# 微映 WeiMirror

微映是一款运行在 Windows 上的 iPad、iPhone 投屏接收程序，支持 USB 数据线和无线 AirPlay。主界面用于连接设备和查看接收状态，收到画面后会打开独立的投屏窗口。

[下载最新版 WeiMirror.exe](https://github.com/GloryPkqa/WeiMirror/releases/latest/download/WeiMirror.exe) · [v1.4.8 发布说明](https://github.com/GloryPkqa/WeiMirror/releases/tag/v1.4.8)

## 界面

USB 和 AirPlay 切换使用带折射的玻璃选中层，并在按下时提供反馈。选中连接方式后，可在下方查看 USB 设备或 AirPlay 接收端名称。接收状态和「显示投屏窗口」位于同一工作区底部。主窗口较宽时，设置分类显示在侧栏，较窄时切换到顶部。

点右上角的「设置」或按 `Ctrl+,` 在主窗口内切换到设置页。点「返回投屏」或按 `Esc` 回到控制台。字号默认 100%，可在「外观」选择主题、深色模式、字体、字号和小、中、大三档界面尺寸。

## 功能

- 支持 USB 投屏及同一台设备断线后自动重连。
- 支持 AirPlay 无线屏幕镜像，默认使用高清自动。也可选择 1080p60、720p30、540p30，以及试验性的 720p60 和 2K60（2560 × 1440）。
- 投屏窗口可置顶、全屏、跟随设备横竖屏调整，并记住上次窗口位置。
- 可选择是否在电脑播放声音，也可以将当前画面保存为原分辨率 PNG。
- 提供连接阶段与常见故障提示，以及用于记录端到端延迟的离线测试页。

预览工具栏默认收起。鼠标移到画面上沿可以显示，按 `F8` 可切换「始终显示投屏工具栏」。画面窗口按 `F11` 切换全屏，`Esc` 退出全屏，`Ctrl+S` 截图，`Ctrl+R` 切换跟随画面比例。

## 使用

需要 Windows 10 或 11 x64，以及 iPad 或 iPhone。首次运行时，点「准备投屏组件」可以在主窗口内选择在线下载、导入官方便携 ZIP 或使用已有目录。在「设置 → 组件」中可以查看组件目录和管理 USB 驱动。

- **无线投屏**：让电脑和设备连接同一局域网，在微映中开启 AirPlay 接收，然后在设备的「屏幕镜像」中选择接收端。
- **USB 投屏**：用支持数据传输的线连接并解锁设备，按需在设备上确认信任，选择设备后开始投屏。程序提供 USB 驱动管理入口。

在「设置 → 投屏」中可以调整无线画质、接收端名称、电脑音频和投屏工具栏。

「高清自动」向设备请求更高的画质上限。接收状态和预览工具栏会显示实际解码的分辨率和帧率。试验档的效果取决于设备和网络，可在「设置 → 工具与关于」打开延迟测试页记录结果，也可导出离线测试页和完整源码。设备端的声音输出由系统和应用决定。

## 从源码构建

源码构建需要 Windows x64、PowerShell 7 和 .NET Framework 4.8。进入项目目录后运行：

```powershell
./build.ps1
```

生成的程序位于 `bin/WeiMirror.exe`，完整源码归档位于 `bin/WeiMirror.Source.zip`，也可在程序中导出。组件位置、官方组件版本和 SHA-256 等详细信息见 [BUILD.md](BUILD.md)。
